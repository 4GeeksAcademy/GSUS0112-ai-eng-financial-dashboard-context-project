# Descripción del Producto

El proyecto es un **Dashboard Financiero** enfocado en proveer métricas ejecutivas y vistas analíticas del flujo de caja de una empresa.

## Funcionalidades Core
- Visualización de KPI financieros principales (Ingresos, Gastos, Neto).
- Gráficos de tendencias de ingresos vs gastos (Income/Outcome Chart) a través del tiempo.
- Análisis de rentabilidad porcentual (Profit Percent Chart).
- Comparación de periodos de negocio (current vs previous).
- Diferenciación de tipos de negocio (B2B vs B2C).
- Detección de alertas sobre aumento de gastos (Outcome Alerts).

## Audiencia / Caso de Uso
El producto está diseñado para directores financieros o administradores que necesitan un "Executive metrics dashboard" (como reza el subtítulo del frontend) para analizar el estado de salud financiera de la empresa de forma rápida.
